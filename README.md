# Academia KIHAP

Site de apresentação de uma academia de artes marciais, desenvolvido em HTML e CSS. Reúne página inicial, dicas, contato e páginas dedicadas às modalidades de Jiu-Jitsu, Karatê e Muay Thai.

O conteúdo apresenta as características e os benefícios das modalidades, além de opções de planos e mensalidades, ajudando visitantes a conhecer a academia e suas atividades.
